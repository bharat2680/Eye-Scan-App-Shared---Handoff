# Fundus DR Fitting v1 Baseline Scaffold

This folder is a baseline evaluation-only training scaffold for
`fundus_dr_fitting_v1`.

It uses:

- `Google Colab/Fundus DR Hem Exudate Separation/review_manifests/fitting_manifest_v1.csv`

The intended four-class task is:

- `normal_or_non_specific`
- `dr_pattern_dominant`
- `exudate_macular_pattern_dominant`
- `mixed_hemorrhage_exudate_pattern`

This scaffold is for baseline experimentation only.

- No app integration is approved from this scaffold.
- No production claims are supported by this scaffold.
- No training is run by this scaffold in the repository.
- No model files, weights, exports, or TFLite artifacts are created here.
